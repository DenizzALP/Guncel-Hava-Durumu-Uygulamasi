# Weather App

This is a simple web application that provides weather information for a city entered by the user. It uses the OpenWeatherMap API to fetch the weather data and display the temperature, weather description, and the min/max temperatures.

## Features

- You can enter the name of a city to check the weather.
- Real-time weather data is fetched from the OpenWeatherMap API.
- Displays the temperature, weather description, and min/max temperatures.

## Usage

1. Clone the project to your local machine:

    ```bash
    git clone https://github.com/DenizzALP/Guncel-Hava-Durumu-Uygulamasi.git
    cd Guncel-Hava-Durumu-Uygulamasi
    ```

2. Open the HTML file in your browser to use the app.

3. No server is required to run the app; simply open the HTML file in a browser.

## API

The weather data is fetched from the OpenWeatherMap API. The API endpoint is as follows:
https://api.openweathermap.org/data/2.5/weather?q={cityName}&appid={API_KEY}&unit=metric&lang=tr


You can get your API key by signing up at [OpenWeatherMap](https://openweathermap.org/current).
